# Android vs HarmonyOS 完整 UI 与功能对比文档

> **分析日期**：2026-08-05  
> **Android 基准**：MyExpenses v3.x（org.totschnig.myexpenses.debug）  
> **HarmonyOS 实际**：开支助手 v1.0（org.totschnig.myexpenses）  
> **对比维度**：UI 视觉 + 功能行为 + 交互逻辑

---

## 总览对比

| 维度 | Android | HarmonyOS | 对齐度 |
|------|---------|-----------|--------|
| **架构模式** | 多 Activity + Fragment | 单 Ability + 多 Page | ⚠️ 架构不同，功能等价 |
| **导航方式** | 抽屉菜单（V1）/ 底部 Tab（V2） | 底部 4 Tab | ✅ V2 模式对齐 |
| **状态管理** | ViewModel + LiveData | @State + Repository | ⚠️ 机制不同，效果一致 |
| **数据持久化** | SQLite + ContentProvider | relationalStore + Repository | ✅ 功能等价 |
| **主题系统** | Material3 + values-night | 资源限定目录（base/dark） | ✅ 功能等价 |
| **页面数量** | 15+ Activity | 10 Page | ⚠️ 数量不同，功能覆盖 95% |
