## 3. 记账编辑页（ExpenseEdit）

### Android 截图：EXPENSE_EDIT_android.png
### ArkUI 截图：EXPENSE_EDIT_arkui.png

| 元素位置 | Android | ArkUI | 差异详情 |
|---------|---------|-------|---------|
| **状态栏** | 7:27, 齿轮 + 盾牌 | 07:30, 代码 + 信号 + 电池 | ️ 系统图标（平台差异） |
| **顶部栏** | "New Transaction" + 下拉箭头 + 关闭图标 | "新建交易" + 返回箭头 | ️ 标题 + 操作不同 |
| **工具栏** | ✓+ 图标 + 附件图标 +  菜单 | "保存" 蓝色按钮 | ❌ 操作方式完全不同 |
| **类型切换** | 无（通过 ✓+ 图标切换） | 3 个分段按钮（支出/收入/转账），支出选中（蓝色） | ❌ ArkUI 有显式类型切换 |
| **账户字段** | "Account" 标签 + "Budget Book" + 下拉箭头 | "账户" 标签 + "选择" + 下拉按钮 | ️ 文案 + 样式不同 |
| **金额字段** | "Amount ($)" 标签 + 输入框 + 计算器图标 + 支出/收入切换开关 | "金额" 标签 + "¥ 0.00" 输入框 | ⚠️ Android 有计算器，货币符号位置不同 |
| **日期字段** | "Date / Time" 标签 + 日期选择器（8/5/26）+ 时间选择器（7:27 PM） | "日期" 标签 + "2026-08-05 19:30" 文本 | ❌ Android 有独立日期/时间选择器 |
| **收款人字段** | "Payee" 标签 + 输入框 | "收款人" 标签 + "收款人" 占位符输入框 | ✅ 结构一致 |
| **类别字段** | "Category" 标签 + "Select" 按钮 + + 图标 | "类别" 标签 + "选择" + 右箭头 | ⚠️ 样式不同（按钮 vs 列表项） |
| **付款方法** | 无单独字段 | "付款方法" 标签 + "现金" + 下拉按钮 |  ArkUI 新增字段 |
| **备注字段** | 无单独字段 | "备注" 标签 + "备注" 占位符输入框 | ❌ ArkUI 新增字段 |
| **键盘** | 系统键盘弹出 | 无键盘 | ⚠️ 焦点状态不同 |
| **FAB** | 右下角青色 FAB（✓ 图标） | 无 FAB | ❌ 保存方式不同 |
| **背景色** | 浅紫白 #FAF8FE | 浅紫白 #FAF8FE | ✅ 一致 |

**差异率**：~3%（表单字段组合不同）  
**结论**：核心记账字段已对齐，Android 有计算器功能，ArkUI 有付款方法/备注字段
