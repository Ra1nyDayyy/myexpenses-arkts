## 重点 FAIL

1. **ACC-006 不分组显示失效**（P1）：点击"不分组"后 Preference `grouping` 已更新为 0，但账户列表仍按类型分组渲染，分组菜单选中态也不刷新，需切 Tab/重启才能观察到变化（实测重启后仍显示分组）。
2. **ACC-009 排序对话框"确定"按钮无法关闭**（P1）：选择排序项后点"确定"能把 `sort_by` 写入 Preference（保存功能正常），但对话框不关闭，只能靠 Back 键退出，交互严重受损。
3. **ACC-011 账户详情弹窗金额整体放大 100 倍**（P1）：详情弹窗显示银行卡收入 ¥800000.00、支出 -¥2800.00、当前余额 ¥797200.00，而页面实际为 ¥8000.00 / -¥28.00 / ¥7972.00（分→元换算丢失）。
4. **ACC-016 删除有交易账户无确认且产生孤儿交易**（P1）：删除有交易的银行卡时无任何确认提示直接删除，且其 2 笔交易在 transactions 表中残留（account_id=2 引用已删除账户），破坏数据完整性。
5. **ACC-020 现金账户交易列表显示为空**（P1）：从资产负债表点击"现金"进入交易页，现金账户在 DB 中有 6 笔交易（房租/聚餐/午饭/转账等），但页面显示"还没有交易"，交易列表未渲染。
