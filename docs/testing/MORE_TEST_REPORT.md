## 重点 FAIL

1. **MORE-019 新建预算金额未保存（P1）**：新建预算填写名称 b1、金额 5000 并选择账户"现金"后点"确定"，budgets 表成功插入 id=1(b1, account_id=1, CNY)，但 `budget_allocations` 表无任何记录，页面金额显示 "未设置描述 · ¥0.00"。源码 `BudgetManage.addBudget` 将 `budgetAmount=parseFloat(amount)*100` 存入内存模型，但 `Repository.insertBudget` 只 insert `budgets` 表、不写 `budget_allocations`，导致预算金额永久丢失、列表恒显 ¥0.00。
2. **MORE-006 类别管理入口缺失（P1）**：设置→数据→"管理类别"点击仅弹出 Toast "跳转到类别管理"，未进入 CategoryManage 管理页；付款方式/标签入口同理（"跳转到付款方式管理"/"跳转到标签管理"）。完整更多 Tab 的 CategoryManage/MethodManage/TagManage 页面虽在路由表中注册，但"更多"Tab 仅弹出 3 项底部菜单（预算编制/交易对手债务/设置），类别/付款方法/标签/资产负债表无任何 UI 入口，导致类别 CRUD、付款方法 CRUD、标签管理（含交易绑定标签）全部不可达。

## 附加发现（未列入主计划但值得关注）

1. **"更多"Tab 完整列表不可达**：源码 Index.ets moreTab() 定义了 7 项完整列表（类别/付款方法/标签/资产负债表/预算编制/交易对手债务/设置），但点击"更多"Tab 仅弹出 3 项底部菜单（moreSheetVisible=true），类别/付款方法/标签/资产负债表无入口，导致 CategoryManage/MethodManage/TagManage/BalanceSheet 页面虽注册路由却不可达（P1）。
2. **预算金额持久化缺陷**：见 MORE-019，insertBudget 未写 budget_allocations，与 Android 原版预算金额保存行为不符（P1）。
3. **预算/债务无编辑功能**：预算、债务列表行点击均无编辑入口，仅新建+删除，与 Android 对应页的编辑能力不符（P2）。
4. **未映射交易作为转账开关状态不同步**：点击开关后视觉为开启（蓝色），但副标题仍显示"关闭"，需重启刷新才可能同步（P3，源码 SettingsData buildSwitchItem 未在 onChange 后更新 summary 文本）。
