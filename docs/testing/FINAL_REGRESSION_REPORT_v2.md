## 重点 FAIL（1 项，P1）

1. **FR-05 / ACC-009 排序对话框"确定"仍无法关闭**：选择"使用次数"并点击"确定"后，排序功能已生效（账户列表重排，银行账户组由 支付宝/旅行基金/银行卡 变为 支付宝/银行卡/旅行基金，sort_by 偏好写入 usages），但**对话框始终不关闭**，只能通过点击遮罩（autoCancel）或重启应用关闭。源码根因：`Index.ets showSortDialog()` 使用**局部变量** `const dialog = new CustomDialogController(...)` 创建对话框控制器（Index.ets:1796），controller 未保持强引用，`SortDialog` 组件内确定按钮的 `this.controller?.close()` 调用失效；与 FR-12 此前修复的拆分计算器为同一类根因，但本处未做同样修复（未改为成员变量持有）。
