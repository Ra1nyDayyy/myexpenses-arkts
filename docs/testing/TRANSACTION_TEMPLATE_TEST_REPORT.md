## 重点 FAIL

1. **TT-004 新增拆分无法完成（P1）**：拆分项金额计算器（CustomDialog）的"确定/取消"按钮在模拟器上点击无任何响应（数字键可正常输入，底部行按钮不可点），导致拆分项金额无法确认写入、对话框无法关闭，拆分交易创建流程被阻断。主表单金额计算器的"确定"按钮可正常点击（已验证），仅拆分项计算器异常，疑为拆分场景 CustomDialog 事件分发问题。
2. **TT-018 多选模式点击交易行误弹详情/操作菜单（P1）**：进入多选模式后，点击交易行中部本应切换选中状态（Index.ets `onClickTransaction` 多选分支 `toggleSelect`），但实际多次弹出"交易详情"弹窗或"详细信息/编辑/删除"操作菜单（bindMenu），与多选语义冲突，多选操作易被误触发。
3. **TT-022 删除交易后汇总卡片未即时刷新（P1）**：通过 UI 删除一笔交易后，交易列表已刷新（该笔消失），但顶部"当前余额/Total"汇总卡片仍显示删除前的旧值（DB 已更新，UI 卡片未同步）。切换账户再切回、甚至 force-stop 重启前均不刷新，需重启应用才恢复一致。根因疑为 `deleteTransaction` 后 `refreshTransactions` 只刷新列表数据、未触发汇总卡片 `recalcSummaries`。
4. **TT-003 转账记录缺少 peer 关联字段（P2）**：转账保存后产生双边记录（源账户 -200、目标账户 +200），但两条记录的 `transfer_account`、`transfer_peer` 字段均为空（仅靠金额正负区分方向），无法从数据层面关联转账的成对记录，影响对账/转账撤销等后续能力。（注：标准基线 id=8 转账同为单侧记录，未见双边关联字段。）

## 缺陷汇总

| 编号 | 严重度 | 模块 | 缺陷描述 | 建议 |
|---|---|---|---|---|
| TT-004 | P1 | 交易-拆分 | 拆分项金额计算器"确定/取消"按钮点击无响应，无法确认拆分项金额，拆分创建流程阻断 | 排查拆分场景 CustomDialog 事件分发（与主表单计算器对照） |
| TT-018 | P1 | 交易-多选 | 多选模式点击交易行误弹交易详情/操作菜单，与多选语义冲突 | 多选模式应禁用行 bindMenu/详情触发，仅响应 toggleSelect |
| TT-022 | P1 | 交易-汇总 | 删除交易后"当前余额/Total"汇总卡片未即时刷新，需重启才恢复 | deleteTransaction 后同步触发汇总卡片 recalcSummaries |
| TT-003 | P2 | 交易-转账 | 转账双边记录 transfer_account/transfer_peer 字段为空，无法关联成对记录 | 保存转账时写入 peer 关联字段 |
| TT-028 | NI | 交易-导出 | 导出 CSV 为开发中占位（Toast） | 按计划实现或明确 NOT_IMPLEMENTED |

## 结论

- 交易新增/编辑/删除/结算切换/多选/搜索/筛选/分布图/历史/排序核心流程：通过
- 模板创建/使用/编辑/周期/删除：全部通过
- 阻断性问题 2 项（TT-004 拆分计算器、TT-022 删除后汇总不刷新），交互冲突 1 项（TT-018 多选误弹），数据完整性 1 项（TT-003 转账 peer 缺失）
- 建议优先修复 P1 三项后再回归拆分/多选/删除场景
