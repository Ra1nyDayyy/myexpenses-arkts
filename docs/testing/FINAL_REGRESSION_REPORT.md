## 重点 FAIL（5 项，均 P1）

1. **FR-04 / ACC-006 不分组显示仍失效**：点击"不分组"后 Preference `grouping` 已保存为 0，但账户列表仍按类型分组渲染，重启应用后依旧；分组菜单选中态与偏好不一致（实时刷新滞后）。根因：`AccountListPage.groups()` 中 `AccountGrouping.NONE` 与 `TYPE` 走同一分支（key = `${Account.typeName(type)} (Σ)`），"不分组"未单独处理。
2. **FR-06 / MORE-019 预算金额仍未保存到分配表**：新建预算（金额 5000）后 `budgets` 表有记录（id=2 regbudget），但 `budget_allocations` 为空。根因：`Repository.insertBudget` 向 `budget_allocations` 插入不存在的 `currency` 列，SQLite 报错（hilog：`table budget_allocations has no column named currency`），写入失败且未捕获；预算页仍显示"暂无预算"，未显示 ¥5000。
3. **FR-11 / TT-018 多选模式点击行仍弹操作菜单**：长按进入多选后，点击交易行能切换选中（已选 1→2→3 项）且批量删除/汇总刷新正常，但点击行同时仍弹出"详细信息/编辑/删除"操作菜单，与多选语义冲突。源码已加 `bindMenu(selectionMode ? [] : ...)` 守卫，但安装版行为未生效（疑似未含最新修复或守卫未生效）。
4. **FR-12 / TT-004 拆分项金额计算器确定/取消仍无响应**：拆分模式下添加拆分项→点"金额"打开计算器→输入金额后点"确定/取消"，对话框不关闭、金额未设置（拆分项仍 ¥0.00），只能点击外部关闭。源码已去 customStyle，但安装版按钮点击仍无响应。
5. **FR-16 / AI 多步骤第 2 步查询结果未显示**："记30元饮料，然后查本月支出"执行计划弹窗显示"2 步"但仅列出第 1 步；第 1 步创建交易成功（DB 写入），第 2 步（查本月支出）结果始终未显示；重复一次（记40元晚饭）同样复现。聊天仅显示"第1步：已创建支出交易..."，无"第2步"消息与异常提示。
